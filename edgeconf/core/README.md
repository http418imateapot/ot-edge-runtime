# edgeconf/core

Lightweight embedded key-value configuration engine for Linux edge devices.

Fills the gap between SQLite (too heavy) and plain text files (too fragile) for factory gateways, AIoT sensor hubs and edge nodes.

This directory is a component of the **ot-edge-runtime** monorepo. It was
previously published as the standalone `robust-binary-config` repository; its full commit
history is preserved here.

# edgeconf/patterns

Fault-tolerant C reference patterns for POSIX applications that exchange messages through config files.

Worked examples of safe read/write and change-notification patterns for applications that use a configuration file as their message channel.

This directory is a component of the **ot-edge-runtime** monorepo. It was
previously published as the standalone `robust-config-exchange` repository; its full commit
history is preserved here.

# runtime

Authenticated REST API for managing Linux-native `runc` containers on OT edge devices.

Process isolation and resource limits for OT workloads on a single-board computer, using runc and cgroups directly instead of a full container orchestrator.

This directory is a component of the **ot-edge-runtime** monorepo. It was
previously published as the standalone `runc-edge-api` repository; its full commit
history is preserved here.
